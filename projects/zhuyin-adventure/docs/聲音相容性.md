# v0.2.3 iPhone／Safari 音效修正

線上首頁、操作語音、官方單符號及進階詞語音檔檢查均回應 HTTP 200，與發布檔案一致。原音效僅使用 AudioContext 預設音訊類別；WebKit 記錄指出 iPhone 靜音開關可能使 Web Audio 不可聽見，即使音訊程序完成。

修正：
- 支援 Audio Session API 時，在建立／恢復 AudioContext 前設定 `playback`。未支援此 API 的瀏覽器保留原播放能力。
- 首頁、家長專區與遊戲音效錯誤畫面提供「重新啟用聲音」；由實際點擊建立新 AudioContext，不清除學習紀錄。
- 停止與切換播放不再完全依賴 Safari 的 `onended`；取消可立即結束，並避免在 await resume 之後復活舊播放。
- AudioContext 中斷、啟用逾時與播放結束事件缺失會回報可重試錯誤；失敗不算完成播放，回饋失敗不自動換題。
- 切到背景或離開頁面停止語音。暫停後繼續會在使用者點擊時重新啟用音效，包括已答對而等候自動換題的情況。
- 首頁與家長區顯示播放失敗提示，不再默默忽略錯誤。播放成功文字只說「播放已結束」，不宣稱硬體實際發聲。

仍需使用者在真機確認媒體音量與藍牙／耳機輸出；舊版 Safari 可能仍受靜音模式影響。另有 WebKit 的 Safari 分頁音訊路由失效報告：即使 Web Audio／HTMLAudio API 回報成功，仍完全無聲，需另開 Safari 分頁或結束 Safari 後重開。此情況不能由本網站可靠判定，也不宣稱此修正能消除所有作業系統問題。

測試涵蓋媒體類別設定、不支援 API、序列完整播放、立即取消、啟用途中取消、多播放互斥、中斷、啟用逾時、播放 watchdog、重新建立 context。瀏覽器測試包含真實 MP3 播放、錯誤顯示／恢復、官方符號教學、自動換題／暫停與離線 MP3 解碼；桌面 WebKit 測試不能代表 iPhone 靜音開關的實機驗收。
