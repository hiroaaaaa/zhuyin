# v0.1.1 親子試玩版驗收與後續

## 可直接試玩的流程

首次：首頁 → 開始玩 → 認識注音 → 選符號 → 聽兩次 → 返回選單 → 聽音找注音。熟悉注音的孩子可由家長區勾選已學符號；不能把勾選當成測驗通過。

每回合五題。孩子可重聽、請小兔幫忙或略過；完成後發一張小花貼紙。指令整段模式必須先等語音播完才能按符號。離線使用前等首頁「離線素材已準備好」。

## 自動化驗證

- `npm test`：24 個測試，包含三款評量遊戲四種難度各 10,000 種子，合計 120,000 題；方向邊界、答案合法、無重複盤面、合法題庫、順序、連點、暫停、分類、去重與分母。
- `npm run build`：TypeScript strict 與正式建置。
- `npm run test:e2e`：首頁／37 字形／實際音檔播放／引入及重載、三款作答／錯答／重聽／貼紙、完整快取及離線 37 符號與指令解碼、320px／二次確認清除，以及首頁／家長頁 WCAG AA 自動檢查。
- 瀏覽器測試預設 Chromium 手機與 WebKit iPad 尺寸。WebKit 模擬不代表 iPad 真機，Chromium 模擬不代表 Android 真機。

## 相較完整 V1.1 的本次範圍

已提供四款完整可作答的核心玩法、全部37素材及本機匿名紀錄。以每題分類記錄協助，不提供未驗證的精熟徽章。逐符號僅統計目標符號的聽辨，沒有推出跨模式能力合成分數；方位紀錄目前按遊戲、難度、指令模式與步數分開。貼紙採固定小花，不提供商店或隨機抽獎。只有單一匿名本機設定，沒有多使用者／雲端同步／資料匯入。

後續開發可以在既有規則與資料版本上擴充，需先明確定義遷移、隱私與驗收，再修改程式。

## 本次執行結果（2026-10-11）

- TypeScript 嚴格檢查、正式建置：通過。
- 24 個規則／統計測試與 120,000 題：通過。
- Chromium 手機與 WebKit iPad 尺寸各六個場景：通過（離線提示修正後，重測兩個相關離線場景）。首頁／家長頁自動 WCAG AA 未發現違規；不是人工無障礙認證。
- Chromium 的離線模擬：重新載入、37 個符號及指令音檔解碼通過。
- WebKit 的 `context.setOffline(true)` 會在受 Service Worker 控制的導覽發生內部錯誤，與 Playwright [已知問題 #42775](https://github.com/microsoft/playwright/issues/42775) 相符。另啟動獨立素材伺服器、驗證快取完整與控制生效，再關閉伺服器：重新載入回應來自 Service Worker、37 符號及指令解碼通過。這是伺服器停機控制，不等同 iPad 真機斷網。
- 320×568 的九個選項、重聽與提示皆在首屏可操作，無橫向捲動。
- 正式執行相依套件 `npm audit --omit=dev`：0 個已知弱點。
- 離線素材共 117 件，發布內容約 1.85 MB；每件下載均以 SHA-256 驗證。

修正包含：離線完整下載後仍須等 Service Worker 控制生效才顯示可離線；明確清理前次建置、排除生成器本身輸出的快取檔案；回饋語音說完再開放下一步。

v0.1.1 修正線上核對發現的分組編號問題：第 1 組對應ㄅㄆㄇㄈ，第 9 組對應ㄣㄤㄥ，九組合計完整涵蓋 37 個符號。補上分組篩選的瀏覽器檢查及分組資料驗證。
