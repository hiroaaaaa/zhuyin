# 注音冒險樂園

台灣幼兒園中、大班（4–6 歲）的手機優先親子遊戲。這是可實際作答的 **v0.2.3 親子試玩版**，不是展示畫面。

遊戲網址：https://hiroaaaaa.github.io/zhuyin/

## 已實作

- 認識注音：37 個教育部字形與讀音、重聽、跟讀、同形配對；聽完兩次可引入題庫。
- 聽音找注音：3／4／6／9 選項；只使用已引入符號；優先較少練習的符號並避免最近兩個目標重複。
- 注音九宮格：2×2 四方向入門；3×3 四／八方向與九個唯一絕對位置；座標運算判斷答案。
- 指令小隊長：1–3 步，逐步練習／完整指令；最後一步可加入方位；正確前綴保留、錯序不跳步。
- 無限重聽、三層協助、暖心回饋、可設定 5／10／15／20／30 題一回合的小花貼紙、暫停／離開／技術中斷。
- 家長操作分隔、逐符號及逐模式統計、手動引入已學符號、每回合題數設定、匯出、二次確認清除。
- IndexedDB 本機匿名紀錄；全素材 SHA-256 驗證的離線 PWA；新版只由首頁／家長區啟用。

六款新遊戲：拼音小火車、聲調氣球、缺字小偵探、注音小商店、聲音翻翻樂、注音尋寶地圖。各有四階難度、小教室或已教題庫門檻，以及獨立結果紀錄。詳見 [六款進階遊戲](docs/六款進階遊戲.md)。

## 開發與發布

需要 Node.js ≥20.19（建議 22 或 24）、npm、Python 3（瀏覽器測試的靜態伺服器）。

```sh
cd projects/zhuyin-adventure
npm ci
npm run dev
npm test
npx playwright install --with-deps chromium webkit
npm run release:build
npm run test:e2e
```

`release:build` 先執行 TypeScript 嚴格檢查、Vite 建置與離線清單產生，再把編譯結果放到儲存庫根目錄 `docs/`。Pages 從 `main` 分支的 `/docs` 發布。**每次修改都要重新建置、測試並一併提交原始碼及根目錄發布資料夾**。不是只修改展示畫面。

Vite base 固定 `/zhuyin/`，路由使用 hash，深連結不需伺服器改寫。瀏覽器測試啟動 `127.0.0.1:4173`；不要用 `file://` 測試 PWA。

## 架構

- `src/data/symbols.ts`：37 符號單一清單、分組、內容版本。
- `src/core/rules.ts`：固定種子的生成器、座標、題目驗證、作答狀態與結果分類。
- `src/core/audio.ts`：Web Audio 手勢解鎖、序列播放、記憶體緩衝、停止與錯誤處理。
- `src/core/storage.ts`：匿名紀錄與不重複記分。題目開始先存中斷占位，完成時覆寫，避免關閉後被算成答錯。
- `src/core/offline.ts`、`scripts/make-offline.mjs`：專案範圍的快取、離線完整驗證、新版提示。
- `src/App.tsx`、`src/style.css`：首頁、選單、引入／遊戲、家長 UI 與手機／平板版面。
- `public/audio`、`glyphs`、`fonts`、`licenses`：本機素材與出處，不引用外部 CDN。
- `tests`：12 萬道原有題目及 24,000 道進階題目的生成性檢查、事件／順序／分類／分母測試與完整瀏覽器測試（WebKit 離線使用伺服器停機控制，真機仍待驗證）。

## 學習紀錄的解讀

「已引入」只代表可加入遊戲；不是精熟認證。聽音找注音的逐符號紀錄與方位／指令紀錄分開。分母包含重聽、協助、教學和略過，排除中斷。只有沒有重聽、錯答、提示或中斷的完成列為獨立完成。看文字指令會記為有協助。每題僅記一次、每回合只發一次貼紙，保留最近 1,000 題。

家長專區 → 陪玩設定 → 每回合題目數：預設 5 題，可選 5／10／15／20／30 題。九款作答遊戲共用，從下一回合生效，保留於本裝置並包含在匯出資料；認識注音自由探索不受限制。清除全部紀錄會將題數恢復為 5 題。舊版紀錄自動補入預設值並保留學習進度。

沒有語音辨識，也不對幼兒發音評分；孩子可以跟讀，不開麥克風。沒有倒數、扣生命、排名或登入壓力。
